# Visualizations

Walk-through of `phase_plot!`, `incomes_plot!`, `dependency_graph_plot`, and how to visualize Γ and Φ.

Topics

- Phase plot and incomes plot
- Plotting Γ(y) and Φ(y) vs y for a given scenario
- Dependency graph layout and arrows
- Random vs non-random sampling: comparing distributions

Maintained publication examples live in `manuscript/`; supplementary examples
are generated by `SupplementaryMaterial/scripts/generate_figures.jl`.
